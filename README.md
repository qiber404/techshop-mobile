# TechShop для iPhone

Мобильное учебное приложение на React Native. При первом запуске на телефоне доступен каталог исходного TechShop из 25 товаров с фотографиями, ценами и скидками. Приложение хранит корзину, отзывы, покупки, остатки и настройки в SQLite на устройстве.

Сборка для iPhone работает в авиарежиме. У каждого телефона своя база. Оформление заказа и оплата демонстрационные. В разделе «Профиль → Управление магазином» можно редактировать ассортимент и остатки, подтверждать, отправлять и завершать учебные заказы. Интерфейс поддерживает русский, казахский и английский языки.

## Установка на iPhone с Windows

1. Откройте **Releases** в этом репозитории и скачайте на компьютер файл **TechShop.ipa** из нужного выпуска. Рядом опубликована контрольная сумма SHA-256. Для просмотра каталога и покупок после установки интернет не требуется.
2. Подготовьте AltServer для Windows по [инструкции разработчика](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Подключите разблокированный iPhone кабелем и подтвердите доверие к компьютеру.
3. Удерживая **Shift**, откройте меню AltServer в области уведомлений Windows. Выберите **Sideload .ipa…**, свой iPhone и скачанный файл. Введите свой Apple Account в окне AltServer. Каждый пользователь подписывает свою копию приложения.
4. Если iOS запросит доверие к разработчику, подтвердите его в **Настройки → Основные → VPN и управление устройством**. Если появится запрос режима разработчика, включите его в **Настройки → Конфиденциальность и безопасность → Режим разработчика**, перезагрузите телефон и подтвердите выбор. Откройте TechShop с главного экрана.

При бесплатном Apple Account подпись действует семь дней. Для продления повторно установите приложение до защиты. [Установка IPA и срок действия подписи](https://faq.altstore.io/release-notes/altserver)

### Как собрать свою версию

В своей копии репозитория запустите **Actions → Build TechShop for iPhone → Run workflow**. GitHub проверит TypeScript и тесты, соберёт Release для физического iPhone и сохранит архив в разделе **Artifacts**. При отправке тега вида `v1.0.0` тот же процесс публикует IPA в **Releases**. Подпись выполняется на компьютере пользователя. Стандартные macOS-исполнители GitHub Actions бесплатны для публичных репозиториев. [Условия GitHub](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)

### Вариант через Expo EAS для команды Apple Developer

Понадобятся Node.js 22.18 или новее, Git for Windows, аккаунт Expo и членство в Apple Developer Program. Для сборки и установки нужно подключение к интернету. Expo собирает приложение на удалённом Mac.

1. Распакуйте архив. Откройте PowerShell в папке `TechShop-Mobile` рядом с `package.json`.
2. Установите зависимости и привяжите проект к своему аккаунту Expo.

   ```powershell
   npm.cmd ci
   npx.cmd eas-cli@latest login
   npx.cmd eas-cli@latest init
   ```

3. Зарегистрируйте iPhone для установки. Выполните команду и откройте выданную ссылку или QR-код на этом iPhone.

   ```powershell
   npx.cmd eas-cli@latest device:create
   ```

4. Запустите сборку. При запросе выберите свою команду Apple Developer, подтвердите выпуск подписи и включите зарегистрированный iPhone. Если EAS предложит инициализировать локальный Git-репозиторий, подтвердите. Учетные данные Apple вводите только в официальном диалоге авторизации.

   ```powershell
   npx.cmd eas-cli@latest build --platform ios --profile iphone
   ```

   Если Apple сообщит, что идентификатор `kz.techshop.mobile` занят, задайте уникальный `expo.ios.bundleIdentifier` в `app.json` и повторите сборку.

5. Откройте ссылку готовой сборки на iPhone и нажмите **Install**. Если iPhone запросит режим разработчика, включите его в **Настройки → Конфиденциальность и безопасность → Режим разработчика** и подтвердите после перезапуска. Запускайте TechShop с его иконки.

[Сборка для зарегистрированных устройств](https://docs.expo.dev/build/internal-distribution/) · [Режим разработчика iPhone](https://docs.expo.dev/guides/ios-developer-mode/) · [Apple Developer Program](https://developer.apple.com/programs/)

## Проверка для защиты

1. Включите авиарежим. Откройте TechShop по иконке и найдите HyperX SoloCast.
2. Добавьте два микрофона. Цена за штуку со скидкой — **25 491,50 ₸**. Итог — **50 983 ₸**.
3. Оформите заказ и нажмите «Оплатить тестово». Полностью закройте приложение и откройте его снова. Заказ и статус оплаты будут в разделе «Заказы».
4. В разделе «Профиль → Управление магазином → Статусы заказов» подтвердите заказ, отметьте его отправленным и завершите. Чтобы показать возврат остатков, отмените другой заказ до отправки.
